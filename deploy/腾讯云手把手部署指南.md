# 腾讯云手把手部署指南（海盈通保 → 企业微信）

> 适用：你已注册腾讯云账号，但不熟控制台操作。
> 目标：买一台服务器 + 域名 + 备案 + 免费 HTTPS 证书，把系统跑上公网联调企微。
> 风格：逐菜单点选，照着做。所有 `你的域名` `你的IP` 都要换成你自己的真实值。
> 配套：服务器**内部**的操作（装环境、跑代码）见同目录 `DEPLOY.md`，本指南负责"控制台买东西 + 备案 + 证书"这部分你最懵的。

---

## 0. 先看清总路线与成本

| 步骤 | 做什么 | 花多久 | 花费 |
|------|--------|--------|------|
| 1 | 买轻量应用服务器（Ubuntu） | 5 分钟 | 约 100–200 元/年（新户更便宜） |
| 2 | 买域名 | 5 分钟 | 约 50 元/年（.com/.cn） |
| 3 | ICP 备案（企业，硬门槛） | **1–3 周**（主要等管局） | 免费 |
| 4 | 申请免费 SSL 证书 | 5 分钟 | 免费 |
| 5 | 防火墙开 80/443 | 2 分钟 | 免费 |
| 6 | 连服务器（网页终端） | 2 分钟 | 免费 |
| 7 | 服务器内部署（复制命令） | 30 分钟 | 免费 |

> 最慢的是**第 3 步备案**（1–3 周），建议买完服务器立刻提交备案，审核期间服务器照常能用（先用 IP 测），不耽误你准备其他东西。

## 1. 买服务器（轻量应用服务器 Lighthouse）—— 推荐小白首选

1. 浏览器开 `cloud.tencent.com`，微信扫码登录。
2. 顶部搜索框搜 **「轻量应用服务器」** → 点进产品页（或直接开 `console.cloud.tencent.com/lighthouse/instance/index`）。
3. 点 **「新建」/「创建实例」**。
4. 按下面填（不确定的照推荐填）：
   - **地域**：选 **广州**（你常驻，延迟低；别选中国香港/海外，否则不用备案但企微国内访问慢）
   - **镜像**：选 **「系统镜像」→ Ubuntu 22.04 LTS**
     > 注意：**不要**选「宝塔面板」「WordPress」等应用镜像！咱们是 Flask 自己跑，纯净 Ubuntu 最清爽，宝塔反而添乱。
   - **套餐**：**2 核 4G** + 带宽 4–6 Mbps + 系统盘 60–80 GB（新用户首购常有特价）
   - **登录方式**：设一个 **密码**（记到备忘录），或选「SSH 密钥」并**下载私钥保存**（丢了进不去）
   - **实例名**：随便填，如 `haiyingtongbao`
   - 防火墙先不管（第 5 步再加 80/443，22 默认有）
5. 勾协议 → 立即购买 → 付款。
6. 创建完成后，在**实例列表**能看到一台机器，记下它的 **「公网 IP」**（IPv4，形如 `1.2.3.4`）。

---

## 2. 买域名

1. 顶部搜索 **「域名注册」** → 进入。
2. 搜你想要的，例如 `oa.haiyingtongbao.com`（建议用 `oa.` 前缀代表 OA 系统；或 `oa.公司拼音.com`）。
3. 选 `.com` 或 `.cn`，加购物车结算。
4. 首次购买要创建 **「实名信息模板」**：
   - **企业实名**：填「广东海盈通保智能科技有限公司」营业执照信息（后续备案主体必须一致）
   - 个人实名：填你身份证（但若用企业备案，域名也要企业实名）
5. 付款后，做**域名解析**（让域名指向你的服务器）：
   - 控制台 → **「域名注册」→「我的域名」** → 点你的域名 → **「解析」**
   - 点 **「新手快速解析」** 或「添加记录」：
     - 主机记录：`oa`
     - 记录类型：`A`
     - 记录值：第 1 步记下的 **公网 IP**
     - 保存
   - 等几分钟~几小时生效。验证：本机 `Win+R` 打开 cmd，输 `ping oa.你的域名`，能解析出 IP 就对了。

## 3. ICP 备案（企业，硬门槛，1–3 周）—— 企微强制要求

> 没备案，域名不能开 80/443，企微接不了。企业备案要营业执照，主体和企微（广东海盈通保智能科技有限公司）一致。

1. 腾讯云控制台右上角点 **「备案」**（或搜「网站备案」）→ 进入备案系统。
2. 选 **「企业备案」**，按提示填：
   - 营业执照（统一社会信用代码、公司名）
   - 法人/网站负责人身份证 + 人脸核验
   - 服务器 IP（第 1 步的公网 IP）
   - 网站名称/用途（填「海盈通保OA管理系统」之类）
3. 提交 → **腾讯云初审**（1–2 天，可能电话核实）→ **工信部短信核验**（你手机收验证码，点链接确认）→ **管局审核**（7–15 天）。
4. 备案成功会短信/站内信通知。
   > 坑：备案期间域名不能访问，但服务器一切正常（可先用 IP 测内部署）。审核完再把域名接上。

## 4. 申请免费 SSL 证书（HTTPS 必需）

1. 顶部搜索 **「SSL 证书」** → 进入 SSL 证书控制台。
2. 点 **「申请免费证书」**（或「免费证书」页签 → 申请）：
   - 证书类型：**TrustAsia DV（免费）**
   - 绑定域名：填 `oa.你的域名`
   - 算法：默认 RSA
3. 验证方式选 **「自动 DNS 验证」**（域名在腾讯云解析，系统自动加验证记录，最省事；
   若域名解析不在腾讯云，选「手动 DNS 验证」，按提示去 DNSPod 加一条 TXT 记录）。
4. 提交 → 几分钟内变 **「已签发」**。
5. 点证书右侧 **「下载」** → 选服务器类型 **「Nginx」** → 得到两个文件：
   - `你的域名_bundle.crt`（证书）
   - `你的域名.key`（私钥）
   下载到本机，待第 7 步传到服务器。
   > 有效期：免费 DV 通常 1 年（部分渠道 90 天，以控制台为准）。到期前控制台会提醒，重新下载替换证书文件即可；后续也可配自动续签（进阶，暂不管）。

---

## 5. 防火墙开 80 / 443 端口

**轻量应用服务器**：
1. 控制台 → **「轻量应用服务器」** → 你的实例 → **「防火墙」** 标签。
2. 点 **「添加规则」**：
   - 应用类型选 **HTTP** → 自动填 80，放行
   - 再添加 **HTTPS** → 自动填 443，放行
   - SSH（22）默认已开，别删。
> CVM 云服务器则是在「安全组」里配入站规则 80/443/22。

---

## 6. 连上服务器（不用装软件）

最省事——用腾讯云**网页终端**：
1. 控制台 → 轻量应用服务器 → 你的实例 → 点 **「登录」**（或「远程登录」）。
2. 选 **「ORC 网页终端」**（浏览器里直接出黑窗口，微信扫码或密码登录，不用装 PuTTY）。
3. 登录后进到一个命令行界面，后面所有服务器内操作都在这里粘贴命令。

> 进阶可选：本机装 FinalShell / PuTTY 连（IP + 第1步密码），比网页终端好用，但新手先用网页终端即可。

---

## 7. 服务器内部署（复制命令即可，细节见 DEPLOY.md）

以下在网页终端里**逐条粘贴执行**（每行回车）：

```bash
# ① 装基础环境
sudo apt update && sudo apt install -y python3-venv python3-pip nginx

# ② 上传代码：把本机 haiyingtongbao/ 整个目录传到服务器 /var/www/haiyingtongbao/app
#    （用 FinalShell 拖拽最方便；或 scp；或 git clone）
#    注意：别传 venv/、__pycache__/、*.bat

# ③ 建虚拟环境 + 装生产依赖
cd /var/www/haiyingtongbao/app
python3 -m venv venv
source venv/bin/activate
pip install -r deploy/requirements-prod.txt

# ④ 初始化数据库（自动建表加列，不破坏已有数据）
python seed.py

# ⑤ 配置企微 4 个凭证（换成你的真实值）
export HYTB_WECOM_CORPID="wwxxxxxxxx"
export HYTB_WECOM_AGENTID="1000002"
export HYTB_WECOM_SECRET="xxxxxxxx"
export HYTB_WECOM_DOMAIN="https://oa.你的域名"

# ⑥ 放证书：把第4步下载的 _bundle.crt 和 .key 传到服务器 /etc/nginx/ssl/
sudo mkdir -p /etc/nginx/ssl
#   （FinalShell 拖进去，或 scp）

# ⑦ 配 nginx：改 deploy/nginx_haiyingtongbao.conf 两处后复制过去
#   - 把所有 <你的域名> 换成真实域名
#   - 把证书路径改成腾讯云下载的实际路径（见下方「证书路径改法」）
sudo cp deploy/nginx_haiyingtongbao.conf /etc/nginx/conf.d/haiyingtongbao.conf
sudo nginx -t          # 看到 successful 再继续
sudo systemctl reload nginx

# ⑧ 配开机自启（把 deploy/haiyingtongbao.service 的占位符换成真实值后）
sudo cp deploy/haiyingtongbao.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now haiyingtongbao

# ⑨ 验证
curl -k https://127.0.0.1:5002/login   # 应返回登录页 HTML
```

**证书路径改法**（关键，腾讯云证书不是 certbot 路径）：
打开 `deploy/nginx_haiyingtongbao.conf`，把这两行
```
ssl_certificate     /etc/letsencrypt/live/<你的域名>/fullchain.pem;
ssl_certificate_key /etc/letsencrypt/live/<你的域名>/privkey.pem;
```
改成你第 ⑥ 步放的实际路径，例如：
```
ssl_certificate     /etc/nginx/ssl/oa.你的域名_bundle.crt;
ssl_certificate_key /etc/nginx/ssl/oa.你的域名.key;
```
（其余 `<你的域名>` 也全部换成真实域名）

> 若不想配 systemd，可用 `bash deploy/start_prod.sh` 简易后台启动（停：`pkill -f haiyingtongbao`）。

## 8. 联调企业微信（回顾）

在企微后台「应用管理」建网页应用，填：
- 应用主页：`https://oa.你的域名/wecom/entry`
- 可信域名：`oa.你的域名`（把企微下载的 `WW_verify_*.txt` 传到服务器 `/var/www/wecom_verify/`）
- 网页授权回调域：`oa.你的域名`（不带 https）
- 企业可信 IP：服务器公网 IP
- 可见范围：那 8 类内部管理人员

账号绑定：PC 浏览器开 `https://oa.你的域名/login` → 用 admin 登录 → IT 用户管理 → 给每个员工填「企微 userid」→ 保存。
手机企微「工作台」点应用 → 免密自动进 OA。

## 9. 最容易踩的坑

- **备案主体要和企微一致**（都是广东海盈通保智能科技有限公司），否则后面接企微卡壳。
- **轻量镜像选「系统镜像 Ubuntu」**，别选宝塔/WordPress 应用镜像。
- **证书路径**必须改成腾讯云下载的实际 `.crt/.key` 路径，别留 certbot 占位。
- **防火墙只开 22/80/443**，别图省事全开（安全风险）。
- 免费 DV 证书**有效期短**，到期前控制台提醒，重新下载替换即可。
- 卡住拍截图发我，我帮你定位（控制台操作或服务器命令都行）。
