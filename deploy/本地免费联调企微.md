# 本地免费联调企业微信（0 成本，先验证打通）

> 定位：**0 成本**把企微回调打通、确认「员工点应用免密进 OA」能跑通。
> 不是正式生产：域名是 cpolar 的（非自有、未备案）、免费版不稳定，仅用于开发联调。
> 前提：本机已能双击 `启动系统.bat` 跑起系统（http://127.0.0.1:5002 能登录）。

---

## 0. 原理一句话

你电脑跑 Flask（5002 端口） → cpolar 把 5002 穿透成公网 `https://xxxx.cpolar.cn` → 企微访问这个地址 → 流量转发回你电脑 → 企微校验/回调都能通。cpolar 的域名已备案，所以企微「可信域名」校验能过。

---

## 1. 本机启动 Flask

双击 `启动系统.bat`，浏览器开 `http://127.0.0.1:5002` 确认能登录（admin / 123456）。
保持这个窗口运行（关了服务就没了）。

---

## 2. 装 cpolar（内网穿透）

1. 官网 `cpolar.com` 下载 Windows 客户端，安装。
2. 注册账号（需实名认证），选**免费套餐**。
3. 控制台复制你的 `authtoken`，在 cmd 执行一次：
   ```
   cpolar authtoken 你的authtoken
   ```
4. 启动隧道（映射本机 5002）：
   ```
   cpolar http 5002
   ```
5. 终端会显示：
   ```
   Forwarding: https://xxxx.cpolar.cn -> http://localhost:5002
   Forwarding: http://xxxx.cpolar.cn  -> http://localhost:5002
   ```
   复制这个 **https 地址**（`xxxx.cpolar.cn` 那串），后面要用。
   > 免费版每次重启 cpolar 域名都变；付费可固定子域名（见第 7 步）。

---

## 3. 配企微 4 个凭证（关键：DOMAIN 用 cpolar 地址）

`wecom.py` 用 `HYTB_WECOM_DOMAIN` 拼回调地址，**必须和企微实际访问的域名完全一致**，否则企微报 redirect_uri 不符。

两种方式：

**A. 临时（免费版，域名会变，每次重配）**
打开 `启动系统.bat`，在 `venv\Scripts\python.exe run.py` 这一行**前面**加 4 行 set：
```
set HYTB_WECOM_CORPID=wwxxxxxxxx
set HYTB_WECOM_AGENTID=1000002
set HYTB_WECOM_SECRET=xxxxxxxx
set HYTB_WECOM_DOMAIN=https://xxxx.cpolar.cn
```
（DOMAIN 填第 2 步拿到的当前 cpolar https 地址）
改完保存，**重开 bat** 让环境变量生效。

**B. 永久（推荐，cpolar 固定域名）**
升级 cpolar 付费固定子域名（如 `haiyingtongbao.cpolar.cn`，几十元/年），域名固定后 `HYTB_WECOM_DOMAIN` 设一次永不用改，企微后台也只需配一次。比腾讯云特价还省、且免备案。

> 四种值从企微后台拿：我的企业→CorpID；应用管理→你的应用→AgentId / Secret。

---

## 4. 企微可信域名校验（放校验文件）

1. 企微后台「应用管理 → 网页授权及 JS-SDK → 可信域名」填 cpolar 域名（如 `xxxx.cpolar.cn`）。
2. 下载 `WW_verify_xxxx.txt`。
3. 把这个文件**原样放进项目根 `wecom_verify/` 目录**（目录已建好）。
4. 企微访问 `https://域名/WW_verify_xxxx.txt` → Flask 的 `/WW_verify_<fname>` 路由返回文件 → 校验通过。
   （nginx 环境由 nginx 处理；本地穿透由这个路由兜底，已加好。）

---

## 5. 企微后台其余配置

| 配置项 | 填什么 |
|--------|--------|
| 应用主页 | `https://xxxx.cpolar.cn/wecom/entry` |
| 网页授权回调域 | `xxxx.cpolar.cn`（**不带 https**） |
| 企业可信 IP | 留空（穿透场景企微看到的是 cpolar 服务器 IP，非你本机，一般不需填） |
| 可见范围 | 那 8 类内部管理人员 |

---

## 6. 手机企微测试

手机企微 → 工作台 → 点你建的应用 → 应**免密自动进 OA**。

不通时按序查：
1. Flask 在跑？（本机 http://127.0.0.1:5002 能登录）
2. cpolar 在线？（终端显示 Online，且 https 地址能开）
3. `HYTB_WECOM_DOMAIN` 是否等于**当前** cpolar 域名（免费版变了要改+重启 bat）
4. `WW_verify_xxx.txt` 是否放进 `wecom_verify/`
5. 企微后台「可信域名 / 回调域」是否和当前域名一致

---

## 7. 免费版最大坑：域名每次变

免费版每次重启 cpolar，域名就换 → 企微后台「可信域名」「网页授权回调域」要重改 + 重新下 WW_verify 重放，很烦。

**解法（推荐）**：升级 cpolar **固定子域名**（几十元/年），一次配置永久用。比腾讯云特价更省、且免备案，是本地长期联调/轻量自用的最佳折中。

---

## 8. 安全提醒

- 穿透把你电脑暴露到公网：**只在需要时开 cpolar，联调完关客户端**。
- `run.py` 是 `debug=True`，穿透联调时错误详情会暴露给公网，仅自己测试用，勿长期公网挂（正式生产用 gunicorn 非 debug，见 DEPLOY.md）。
- 这是测试路线；正式给员工日常用，仍建议腾讯云备案方案（合规、稳定）。
