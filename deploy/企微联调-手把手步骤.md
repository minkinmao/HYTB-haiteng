# 企业微信联调 · 手把手操作步骤（本地 cpolar 免费方案）

> ⚠️ **【2026-09-29 结论：本路线已终止，请勿再按本文操作】**
> 企微后台"设置可信域名"填入 cpolar 域名后报红字：**「域名主体校验未通过，需配置备案主体与当前企业主体相同或有关联关系的域名」**。
> 原因（企微官方硬规则）：可信域名除"域名归属校验（放 WW_verify 文件）"外，还要求 **ICP 备案且备案主体 = 企业认证主体**；**第三方服务商域名（cpolar / ngrok / 花生壳 / natapp）一律被拦，无绕法**。
> 因此：**免密登录 + JS-SDK 的唯一前提 = 自有、以公司名义备案的域名**。
> 本文前半部分（cpolar 装好、隧道指 5002、端口排查）仍然有效，可作**临时演示**（应用主页填穿透地址 + 密码登录，无免密）；**正式给员工用请转 `腾讯云手把手部署指南.md` + `DEPLOY.md`**（备案主体公司全称必须与企微认证主体完全一致）。

> 目标：手机上打开企业微信 → 点应用图标 → **不用输密码**直接进 OA。
> 你只需要照着下面 7 步做，每步都有「点哪里」和「看到什么算成功」。

---

## 0. 先看懂你截图里的问题（重要）

你的 cpolar 隧道是通的，但**指向的端口错了**：

| 你截图里的信息 | 说明 |
|---|---|
| `website` 隧道 → `localhost:8080` | ❌ 我们的系统**不在 8080** |
| 我们的系统实际端口 | ✅ **5002**（`run.py` 里写死 `port=5002`） |
| cpolar 给的外网地址 | `https://1d6be8a7.r15.vip.cpolar.cn` |

所以现在这条隧道转发到 8080，是**空的**，企微访问它会 502/超时。
**第一步就是把这个端口改成 5002。**

---

## 1. 确认系统本机能跑

1. 双击 `启动系统.bat`（保持黑窗口开着，别关）
2. 浏览器打开 http://127.0.0.1:5002 → 能看到登录页
3. 用 `admin / 123456` 登录一次，确认系统正常

> 打不开 = 系统没起来，先解决这个，别往下走。

---

## 2. 改 cpolar 隧道端口 → 5002

在 cpolar 网页控制台（就是你截图那个 `localhost:9200` 页面）：

1. 左侧点「**隧道管理**」→「**隧道列表**」
2. 找到名为 `website` 的隧道 → 点右侧「**编辑**」
   > 你截图里 `website` 出现两行（一行 http、一行 https）——这通常是**同一条隧道同时开了两种协议**，改一次即可；如果两行各有独立「编辑」按钮，那就两条都改成 5002。
3. 把「本地地址」从 `http://localhost:8080` 改成 **`http://127.0.0.1:5002`**
4. 保存 → 回到列表，点该隧道的「**停止**」再「**启动**」（或点「重连」）让它生效
5. 记下这条隧道的 **https 地址**，长这样：`https://1d6be8a7.r15.vip.cpolar.cn`

**验证一下通不通**：手机或电脑浏览器直接打开
`https://1d6be8a7.r15.vip.cpolar.cn/login`
→ 能看到我们的登录页 = 隧道通了 ✅（打不开就回看第 1、2 步）

> ⚠️ 免费版注意：**cpolar 重启后这个随机域名会变**。变了就回第 3 步改配置。

---

## 3. 填企微参数（改一个 txt，不碰代码）

用记事本打开项目根目录的 **`wecom_config.txt`**，填 4 个值：

```
CORPID=ww你的企业ID
AGENTID=1000002
SECRET=你的一长串密钥
DOMAIN=https://1d6be8a7.r15.vip.cpolar.cn
```

**这 4 个值从哪抄？**

| 配置项 | 企业微信后台路径 |
|---|---|
| `CORPID` | 「我的企业」→ 页面拉到底 → **企业ID**（`ww` 开头） |
| `AGENTID` | 「应用管理」→ 点开你的自建应用 → 上方 **AgentId** |
| `SECRET` | 同一个页面 → **Secret** → 点「查看」（要管理员在企微里确认） |
| `DOMAIN` | 第 2 步里 cpolar 给的 **https 地址** |

> `DOMAIN` **必须带 `https://`**，**末尾不能有 `/`**。

保存文件 → **关掉黑窗口 → 重新双击 `启动系统.bat`**（配置在启动时读取，必须重启）。

---

## 4. 自检：一条网址看清配置对不对

浏览器（电脑上即可）打开：

```
http://127.0.0.1:5002/wecom/diag
```

（没登录会跳登录页，先用 admin 登进去再打开）

会返回一段 JSON，重点看两个字段：

| 字段 | 期望值 | 不是这个值怎么办 |
|---|---|---|
| `access_token_ok` | `true` | `false` → `CORPID`/`SECRET` 抄错了，或「企业可信IP」没配（见第 5 步，返回 60020 就是这个原因） |
| `oauth_callback` | `https://你的域名/wecom/callback` | 不对 → `DOMAIN` 填错，回第 3 步 |

`jsapi_ticket_ok` 也应是 `true`（它是 JS-SDK 用的，用来调原生拍照/关窗口）。

---

## 5. 企业微信后台配置（4 处）

进「应用管理」→ 点开你的自建应用，往下滚到 **「开发者接口」** 区块。

### 5.1 应用主页（员工点图标落在哪）
页面偏上位置找到「**应用主页**」→ 填：
```
https://1d6be8a7.r15.vip.cpolar.cn/wecom/entry
```
`/wecom/entry` 是免密登录入口，**别填成 `/`**（那样会跳密码登录页）。

### 5.2 可信域名 + 域名归属校验（最关键）
「开发者接口」→「**网页授权及JS-SDK**」→ 点「**设置可信域名**」：

1. 弹窗里点「**下载校验文件**」，得到一个 `WW_verify_xxxxxxxx.txt`
2. 把这个文件**原样**丢进这个目录（文件名一个字都别改）：
   ```
   E:\workbuddy\系统开发\haiyingtongbao\wecom_verify\
   ```
3. 回到企微弹窗，域名栏填（**不带 `https://`**）：
   ```
   1d6be8a7.r15.vip.cpolar.cn
   ```
4. 勾选「**可作为应用 OAuth2.0 网页授权功能的回调域名**」
5. 点确定/校验

> ✅ 校验时企微会去访问 `https://你的域名/WW_verify_xxx.txt`，
> 所以**此刻系统必须在跑、cpolar 必须通、隧道必须指向 5002**，否则校验必失败。
> 代码里已加 `/WW_verify_<文件名>` 路由兜底，放对目录就能应答。

### 5.3 企业可信IP（必须配，否则换不到 token）
同一个应用页面 → 找「**企业可信IP**」→ 填入**你本机对外的公网 IP**。

怎么知道自己的公网 IP？两种方法任选：
- 浏览器打开 https://myip.ipip.net ，显示的那个就是；
- 或打开这条网址（把 corpid/secret 换成你的）：
  ```
  https://qyapi.weixin.qq.com/cgi-bin/gettoken?corpid=你的CORPID&corpsecret=你的SECRET
  ```
  返回里的 `from ip: x.x.x.x` 就是你要加的 IP（返回 60020 是正常现象，就是让你来加 IP 的）。

> ⚠️ 企微规则：**可信域名校验通过后，才能配置可信IP**，所以顺序别颠倒。
> ⚠️ 坑：家用/办公宽带的公网 IP 会变，变了要回来改。这是免费方案的第 2 个大坑。

### 5.4 可见范围
应用设置里「可见范围」只勾那 **8 类内部管理人员**（和我们系统"Web 只给内部人员"的定位一致）。

## 6. 绑定账号（让企微账号 ↔ 系统账号对上）

1. 电脑浏览器登录系统 → 左侧进「**IT · 信息技术**」→「**用户管理**」
2. 给每个员工填「**企业微信 userid**」→ 保存

> userid 是**企微通讯录里的账号**（不是微信昵称、不是姓名）。
> 在企微后台「通讯录」→ 点开某员工 → 「账号」那一栏，形如 `zhangsan` 或 `ZhangSan`。
> 填错的直接后果：那人点应用会提示"尚未绑定系统账号"。

## 7. 手机实测

1. 让企微后台配置保存生效（可信域名校验通过）
2. 手机打开**企业微信** → 底部「工作台」→ 找到你的应用图标 → 点开
3. 期望：一闪 → **直接进 OA 首页**，全程不用输密码

如果没进去，对照下表：

| 现象 | 原因 | 解法 |
|---|---|---|
| 提示"redirect_uri 参数错误" | 回调域没配进可信域名 | 回 5.2，勾选「OAuth2.0 网页授权回调域名」 |
| 提示"企业微信未配置" | `wecom_config.txt` 没填全 / 没重启 | 回第 3、4 步 |
| 提示"尚未绑定系统账号" | 该员工 userid 没绑或填错 | 回第 6 步 |
| 提示"配置错误或接口不可用" | `CORPID`/`SECRET` 错 或 可信IP 没加 | 看 `/wecom/diag` 的 `access_token_ok` |
| 白页 / 502 | 隧道没指 5002、或系统没开 | 回第 1、2 步 |
| 突然又不行了 | cpolar 免费版域名变了 | 改 `wecom_config.txt` 的 `DOMAIN` + 企微后台改可信域名 |

## 8. 免费方案的 3 个硬坑（提前知道，少踩）

1. **域名每次重启会变** → 每次都要改 `wecom_config.txt` + 企微后台改可信域名。
   花几十元升级 cpolar **固定二级域名**可一次性解决，这是最省心的折中。
2. **可信域名要求 ICP 备案、且要在工信网可查** → cpolar 的一级域名 `cpolar.cn` 是备案的，
   但你这个四级子域名能否通过企微校验，**只能试了才知道**。如果 5.2 校验就是过不去，
   说明这条路走不通 → 直接转腾讯云（备案域名），别耗时间。
3. **企业可信IP 要求固定公网 IP** → 家用宽带动态 IP 会变，变了企微接口就报 60020。

> 结论：这套只适合**打通、验证、演示**。
> 一旦确认功能没问题，**正式给员工用还是建议上腾讯云**（域名+备案+固定IP，一年百来块）。
> 那边的手把手指南已经在 `deploy/腾讯云手把手部署指南.md`，两套流程可以无缝切换。

## 9. 安全提醒（别省这一步）

- cpolar 是把你**本机暴露到公网**，联调完记得关掉 cpolar 客户端。
- `run.py` 用的是 `debug=True`（开发模式），**别长期挂在公网**，调试完就关。
- `wecom_config.txt` 里有 Secret，**别截图发群、别传给外部**。
