# ============================================================
#  海盈通保 · 企业微信联调配置（示例模板）
# ------------------------------------------------------------
#  用法：把本文件复制一份，命名为 wecom_config.txt，把等号右边换成你自己的值，保存后重启系统生效。
#  格式要求：KEY=值，等号左右不要空格，行尾不要写注释。
#  生产环境更推荐用环境变量：HYTB_WECOM_CORPID / HYTB_WECOM_AGENTID / HYTB_WECOM_SECRET / HYTB_WECOM_DOMAIN
#  （更安全，且不会随代码一起被提交到代码仓库）。
# ============================================================

# 1) 企业ID —— 企业微信后台「我的企业」→ 拉到底「企业ID」，以 ww 开头
CORPID=<你的企业微信 CorpID，如 wwb9934dd6b93ceb87>

# 2) 应用ID(AgentId) —— 后台「应用管理」→ 点开你的自建应用 → 页面上方的 AgentId，纯数字
AGENTID=<你的应用 AgentId，纯数字>

# 3) 应用密钥(Secret) —— 同一个应用页面 → Secret 点「查看」后复制那一长串
SECRET=<你的应用 Secret>

# 4) 公网地址 —— 你的域名，必须带 https:// 开头，末尾不要加斜杠
#    例子：https://oa.your-company.com
DOMAIN=<你的公网域名，如 https://oa.your-company.com>
