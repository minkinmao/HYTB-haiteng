② 怎么拿到免费的 Key

三分钟搞定，不用付费。
  • 打开 bigmodel.cn（智谱开放平台），手机号注册 + 实名认证
  • 进「控制台 → API Keys → 创建新的 Key」，复制保存（只显示一次）
  • 回来粘贴到左侧「API Key」，点保存 → 点测试连接
  • 接口地址填 https://open.bigmodel.cn/api/paas/v4，模型名 glm-4-flash
为什么不用免费的网页版抓取？
协议是 PDF / Word 的复杂表格，只有大模型能读懂「哪个数字是 FYC、哪个是第 3 年 RYC」。 规则抓取会把表格读串，填错数据比不填更麻烦。
数据安全
协议正文会发到所选服务商的接口做识别（智谱在国内，数据不出境）。 如果你不希望某份协议外发，就别用机器人识别，手工录入即可 —— 系统不做任何强制上传。
机器人的边界（重要）
AI 只生成「待审草稿」，草稿不会出现在合约列表里的正常数据中； 你必须在打开的编辑页逐项核对、点保存，它才转为正式合约。 抽错、抽漏都非常正常 —— 协议表格错位是常态，人工那一眼不能省。
