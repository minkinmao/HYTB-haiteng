字段统称：首年基础佣金 = FYC，第二年~第五年采购 = RYC2 / RYC3 / RYC4 / RYC5；首年佣金 = FYC + 首年方案；投保区域统称 销售分公司。
层级视图：「全部」显示首年明细三列（FYC / 首年方案 / 首年佣金）；选股东 / 子公司 / 团队长层面时不重复展示这三列，只保留该层面的结果。
「全部」与「股东层面」额外展示各年 RYC 采购成本（第二年~第五年采购，原始百分点，未经系数折算），与最右侧「RYC续年度佣金」（采购 × RYC 佣金比例%）区分：前者是采购成本、后者是实算佣金；选子公司 / 团队长层面时不展示 RYC 采购成本列。
三层口径：股东＝签约费用（Σ各采购项）；销售净费 = 首年佣金 × 净费比例%，其中净费比例 = 基础佣金比例 + 销售费用比例 + 经营费用比例（按渠道自动测算：当前线下 {{ '%.2f'|format(net_ratio_both.offline) }}%、互联网 {{ '%.2f'|format(net_ratio_both.internet) }}%；第三位起直接舍去，保留 2 位小数）； 子公司＝FYC首佣（首年佣金×基础佣金比例% + Σ各年RYC×该年RYC佣金比例%）+ 销售费用（取整规则((FYC+首年方案)×销售费用比例%)，仅首年）+ 经营费用（(FYC+首年方案)×经营费用比例%，仅首年）； 团队长＝FYC首佣（与子公司一致）。所有数值均为占保费的百分比；采购成本为 0 时留空。
报表最右侧四列为 RYC续年度佣金（各年 RYC × 该年 RYC 佣金比例%，0 表示该年续期佣金为 0%、不再沿用基础佣金比例；分年期、每年可不同；各层级一致）。
RYC续年度佣金取值规则（二改 2026-11-03）：① 所有 RYC续年度佣金数据取整数值（直接舍去小数，非四舍五入），展示时保留 1 位小数（如 2 → 2.0%）；② 系数设置弹窗勾选「RYC续年度佣金 < 1% 自动置空」后，低于 1% 的自动留空（线下 / 互联网统一生效，月度备份一并记录）。
销售费用取整规则（一律直接舍去，四舍五也舍）：① 保留2位小数（第三位起舍去） ② 取整（小数舍去） ③ 减1%后保留2位（默认）——即先 ×99%（减 1%），再由第三位起舍去（如 2.15% → 2.12%）。 销售分公司筛选：选具体省/市会同时带出标注「全国」的产品（全国含该省）；选中具体省份后，列表中该列只显示所选省份。
